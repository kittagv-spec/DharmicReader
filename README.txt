Dharmic Text Reader v3.6 FINAL
Dharmic Reader is a text translator from Sanskrit or Hindi to English and Kannada.
It also reads out in Hindi for original data and translated English and Kannada.
Data is Json files. These files are created from PDFs via python code through OCR into its original Sanskrit or Hindi.
These Json files are inputs to the program which translates and reads out in English and / or Kannada. Also reads out the original text in Hindi.

English TTS: Prabhat when exposed; otherwise en-IN; otherwise English. Non-Prabhat English is slowed to rate 0.68 for clarity.
Exit: visible Exit button, native bridge attempts, then browser history/close best effort. Normal PWAs cannot forcibly close themselves due to browser security.
Service-worker cache: dharmic-reader-v3-5-final.
