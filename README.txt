Dharmic Text Reader v3.5 FINAL
This is a text translator from Sanskrit or Hindi to English and Kannada. 
Also reads out the text in English, Kannada and Original text in Hindi.
It takes Json files converted from pdf using python code via OCR or direct and those are json files are to be loaded in the program. 

English TTS: Prabhat when exposed; otherwise en-IN; otherwise English. Non-Prabhat English is slowed to rate 0.68 for clarity.
Exit: visible Exit button, native bridge attempts, then browser history/close best effort. Normal PWAs cannot forcibly close themselves due to browser security.
